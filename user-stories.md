# User Stories

- As a user, I want to add a new book (title, author, genres, plot summary, page count) so that I can keep a record of what I've read.

- As a user, I want to pick genres from a list when adding a book, or type my own custom genre, so that I can categorize a book the way I actually think of it.

- As a user, I want the app to tell me if a book with that title already exists so that I don't accidentally add the same book twice.

- As a user, I want to add a theme note to a book, including the page number where I noticed it, so that I can capture how a theme showed up at that point in the story.

- As a user, I want to add another theme note to a book that already has one so that I can track more than one theme in the same book. (Loop)

- As a user, I want to view a list of all my books so that I can browse what I've logged.

- As a user, I want to look up a book by title, without worrying about capitalization, and see all of its theme notes in one place.

- As a user, I want to update a book's details so that I can fix mistakes or add information later.

- As a user, I want to update a theme note so that I can revise my thinking after re-reading or reflecting more.

- As a user, I want to delete a theme note so that I can remove one that no longer applies.

- As a user, I want to delete a book so that my list stays accurate, with its theme notes removed along with it.

- As a user, I want to be warned if I try to log a theme note on a page that doesn't exist in the book, so that my notes stay accurate.
